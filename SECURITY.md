# Security Policy

## Scope

This repository may contain project documentation and approved website-related assets. The live website is hosted separately on Blogger.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details, credentials, personal information, or sensitive logs in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Otherwise, contact the repository owner through a private channel listed on their GitHub profile.

Include only the information needed to understand and reproduce the issue safely:

- A concise description
- Affected component or URL
- Potential impact
- Safe reproduction steps, if available
- Suggested mitigation, if known

## Security expectations

- Never commit passwords, API keys, session cookies, access tokens, or private keys.
- Never upload patient-identifiable or confidential health information.
- Keep dependencies and website components under review.
- Use least-privilege access and enable multi-factor authentication on relevant accounts.
- Test changes in a non-production environment where possible.

Please allow the maintainer reasonable time to investigate before public disclosure.
